Omni AI Suite is a modular, high-performance AI Content Studio for WordPress with real-time SSE streaming, BYOK, and zero database bloat.

== Description ==
(توضیحات کامل افزونه را اینجا بنویسید. به قابلیت‌های کلیدی مثل تبدیل خودکار Mermaid به تصویر محلی SVG، پشتیبانی کامل از جداول و هدینگ‌های گوتنبرگ، و استریم زنده اشاره کنید.)

== Installation ==
1. Upload the plugin files to the `/wp-content/plugins/omni-ai-suite` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' screen in WordPress.
3. Go to the Omni AI Suite Settings and add your API keys (Gemini, OpenAI, or Claude).
